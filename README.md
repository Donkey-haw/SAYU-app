# SAYU

선생님의 생각에서 시작하는 수업 설계 — Mac용 교사 파일럿 체험판의 소개 사이트입니다.

사이트: https://donkey-haw.github.io/SAYU-app/

- `src/pages/*.html`을 고치고 `python3 build.py`로 `public/`을 만듭니다.
- `main`에 올리면 GitHub Actions가 `public/`을 GitHub Pages로 배포합니다.
- 체험판 파일은 이 저장소의 Releases에 올리고, 주소를 `public/assets/site.js`의 `downloadURL`에 적습니다.

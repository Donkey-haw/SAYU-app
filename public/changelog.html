0.12.6 체험판

2026년 11월 17일 · 보드 폴더

바뀐 것

  • 설정 › 작업 공간 › 보드 폴더에서 폴더를 정하면, 완성한 보드가 그 폴더에 보드 이름 그대로 저장됩니다. AI가 고치면 같은 파일이 새 내용으로 바뀌고, ‘Numbers에서 열기’도 이 파일을 엽니다.
  • 그 파일을 직접 고치면 다음 AI 수정이 고친 내용에 이어서 진행됩니다.

알아 두세요

  • AI가 작업하는 동안 같은 파일을 고쳤다면 덮어쓰지 않고, 옆에 ‘(AI 수정 날짜)’ 파일을 따로 만듭니다.
  • iPad에서 쓰려면 iCloud Drive 안의 폴더를 고르세요.

0.12.5 체험판

2026년 11월 17일 · 멈춘 작업 이어 가기

바뀐 것

  • AI 응답을 중간에 멈춰도 다음 요청에서 하던 작업을 이어 갑니다. 처음부터 다시 읽지 않아 시간과 사용량이 줄어듭니다.

0.12.4 체험판

2026년 11월 17일 · 보드에 새 시트를 한 번에 넣기

바뀐 것

  • 같은 단원 보드에 이번 차시 시트를 이어 만들 때, AI가 시트 하나를 먼저 다 설계한 뒤 도형·글·그림·이름표를 한 번에 넣습니다. 지금까지는 기둥·섹션마다 나눠 넣어서, 넣을 때마다 시간과 사용량이 더 들었습니다.
  • 표·영상·링크처럼 따로 넣어야 하는 것은 그대로 따로 넣습니다. 넣은 뒤 시트마다 검사하고 고치는 과정은 바뀌지 않습니다.

0.12.3 체험판

2026년 11월 17일 · 보드 작업 사용량 줄이기, 보드 사본 정리

바뀐 것

  • 보드가 아직 없는 차시에서 같은 단원 보드에 이어 만들 때, 앱이 그 단원의 현재 보드를 AI에게 바로 알려 줍니다. AI가 여러 사본 가운데 하나를 짐작해 고르지 않습니다.
  • 큰 시트의 배치 검사 결과를 AI가 끝까지 읽을 수 있게 줄였습니다. 보드 도구의 결과도 같은 내용을 더 짧게 전달해 보드 작업의 사용량이 줄어듭니다.
  • 요소를 복사해 붙여 넣는 보드 도구가 도형 윤곽 때문에 실패하던 문제를 고쳤습니다.
  • AI가 보드를 고칠 때마다 쌓이던 사본을 정리합니다. 보드마다 현재 버전과 바로 이전으로 되돌릴 사본만 남기고, 나머지는 앱을 켤 때와 요청이 끝날 때 휴지통으로 보냅니다.

알아 두세요

  • 보드 목록에 있던 이전 버전은 가장 최근 것 하나만 남습니다. 지운 버전은 Mac 휴지통에서 되살릴 수 있습니다. 이전 답변에 걸린 오래된 버전 링크는 열리지 않을 수 있습니다.
  • 다음 버전을 만든 뒤에 직접 고친 이전 버전, 보관한 수업의 보드, 아직 복구를 기다리는 작업은 정리하지 않습니다.

0.12.2 체험판

2026년 11월 16일 · AI 사용량 줄이기 2단계

바뀐 것

  • 한 수업의 대화가 길어져 AI가 다시 읽는 양이 일정 크기를 넘으면, 다음 질문에서 대화를 새로 정리해 이어 갑니다. 앱이 수업 기록과 최근 대화를 다시 전달합니다. 보드 만들기·고치기처럼 AI를 여러 번 부르는 작업이 긴 대화 뒤에 와도 구독 사용량이 크게 늘지 않습니다.
  • 같은 대화에서 이미 받은 다른 차시 기록 같은 참고 자료를, 중간에 다른 질문을 했다는 이유로 다시 받지 않습니다.

알아 두세요

  • 대화를 새로 정리한 뒤에는 AI가 앞서 도구로 본 보드 화면이나 자료 전문을 기억하지 않습니다. 필요하면 다시 확인합니다. 그 질문만 답이 조금 늦을 수 있습니다.
  • 이번 업데이트로 진행 중인 대화가 처음부터 다시 정리되지는 않습니다.

0.12.1 체험판

2026년 11월 16일 · AI 사용량 줄이기 1단계

바뀐 것

  • 대화를 이어 갈 때 AI가 이미 받은 작업 지침, 수업 기록, 메모를 매번 다시 받지 않습니다. 바뀐 부분만 새로 받습니다. 같은 대화에서 쓰는 구독 사용량이 줄어듭니다.
  • AI가 직접 수업 기록에 적은 내용은 다음 질문 때 다시 보내지 않습니다. 선생님이 그 뒤에 고친 기록은 그대로 새로 보냅니다.

알아 두세요

  • 업데이트 뒤 수업마다 첫 질문에서 AI가 대화를 한 번 새로 정리합니다. 앱이 그동안의 대화와 기록을 다시 전달하므로 이어서 쓰면 됩니다. 이때만 답이 조금 늦을 수 있습니다.

0.12.0 체험판

2026년 11월 15일 · 정식 앱 이름표와 기록 폴더

바뀐 것

  • 앱의 이름표(식별자)와 수업 기록 폴더를 정식으로 바꿨습니다. 새 SAYU를 처음 열면 이전 체험판의 수업 기록을 그대로 가져옵니다. 이전 기록 폴더는 백업으로 남겨 둡니다.
  • 이전 SAYU가 열려 있으면 먼저 종료해 달라고 안내합니다. 쓰는 중인 기록을 옮기지 않기 위해서입니다.

한 번만 해 주세요

  • 0.11 체험판에서는 앱 안에서 바로 바꿀 수 없습니다. 앱이 새 버전을 알려 주면 내려받기에서 한 번 받아 응용 프로그램 폴더의 SAYU를 바꿔 주세요. 그다음부터는 앱 안에서 업데이트됩니다.
  • 처음 열 때 ‘그래도 열기’와 손쉬운 사용·Numbers 제어 권한을 한 번 다시 허용합니다.

0.11.4 체험판

2026년 11월 15일 · 조용한 업데이트 알림

바뀐 것

  • 새 버전을 찾아도 작업 중인 화면 위로 창이 뜨지 않습니다. 사이드바 아래에 새 버전 단추가 생기고, 원할 때 눌러 바뀐 점을 보고 설치합니다.
  • 업데이트 창에 그 버전에서 바뀐 점만 짧게 보입니다. 전체 기록은 창의 버전 기록 단추로 엽니다.

0.11.3 체험판

2026년 11월 15일 · 앱 안에서 업데이트

새로 생긴 것

  • 새 버전이 나오면 앱이 알려 주고, 버튼 한 번으로 내려받아 설치합니다. 메뉴의 SAYU › 업데이트 확인…으로 직접 확인할 수도 있습니다.
  • 설정 › 실행 환경에서 현재 버전을 보고, 자동 확인을 끄거나 켤 수 있습니다.

0.11.2를 쓰고 계시면 이번 한 번만 내려받기에서 직접 받아 바꿔 주세요. 그다음부터는 앱이 업데이트합니다.

0.11.2 체험판

2026년 11월 15일 · 교사 파일럿을 위한 첫 공개 체험판

새로 생긴 것

  • AI가 일하는 단계가 대화 안에 바로 보입니다. 끝나면 몇 단계를 몇 초 동안 했는지 접어 둡니다.
  • 대화를 지울 수 있습니다. 대화만 지울지, 그 수업의 문서와 보드까지 휴지통으로 옮길지 고릅니다.
  • 수업 문서의 시계 단추로 이전 버전을 같은 창에서 읽고 되돌릴 수 있습니다.
  • PDF와 이미지를 대화창이나 자료 창에 끌어다 놓아 연결할 수 있습니다.
  • 앱 아이콘이 생겼습니다.

바뀐 것

  • 설정의 ‘교육철학·학급’과 ‘나의 수업 설정’을 하나로 합쳤습니다.
  • 지침 탭에는 교육 철학·지침과 함께 쌓은 통찰만 보입니다. 보드 출력물 같은 작업 파일은 수업 문서에서 봅니다.
  • 앱 안의 출판사 사이트 브라우저는 잠시 뺐습니다. 출판사 자료는 평소 쓰는 브라우저에서 내려받아 연결해 주세요.
  • 작업 공간에서 읽은 내용이 웹 주소에 담겨 밖으로 나가지 않도록 확인을 더했습니다.

고친 것

  • 설정에서 지침의 ‘열기’를 누르면 앱 창이 닫히던 문제를 고쳤습니다.
  • 수업 문서의 이전 버전이 마크다운 기호 그대로 보이던 문제를 고쳤습니다.
